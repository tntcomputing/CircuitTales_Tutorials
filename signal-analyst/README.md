# Signal Analyst Tutorial

A MakeCode tutorial for the micro:bit that teaches basic programming concepts through interactive signals and user interactions.

## What you'll learn

- How to display text on the micro:bit
- Using button inputs to trigger actions
- Working with gestures like shake
- Creating conditional logic with if/else statements
- Using random functions for unpredictable behavior
- Displaying LED patterns

## How to use this tutorial

1. Go to [MakeCode for micro:bit](https://makecode.microbit.org)
2. Click on "Import" or use the GitHub import feature
3. Enter this repository URL
4. The tutorial will load automatically

## Tutorial URL

Load this tutorial directly with:
```
https://makecode.microbit.org/#tutorial:github:YOUR_USERNAME/signal-analyst-tutorial
```

## About

This tutorial is part of the CircuitTales project, designed to make programming education engaging through storytelling and interactive activities.
